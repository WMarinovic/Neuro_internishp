The Python you need Python

PsychoPy experiments are ordinary Python, and this module uses only a small part of the language. If you have written Python before, skim this part and go on to 1.5. If you have not, work through it first: the four boxes below run real Python in your browser, so you can change the code and see what happens without installing anything.

Note

PsychoPy itself cannot run in a browser, because it needs a real window on a real screen. The boxes here run plain Python only. From 1.5 onwards you type the code into the PsychoPy Coder on your own computer.

1.1Values and variables

A variable is a name for a value. You create one with a single =, and from then on the name stands for the value. Numbers with a decimal point are floats, whole numbers are ints, and text in quotes is a string, str. An f-string, a string with an f in front, lets you drop values into text inside curly brackets, and :.0f rounds to no decimal places.

1.2Lists

        
A list holds several values in order, inside square brackets. You reach one item by its position, its index, and Python counts from 0, so the first item is [0]. A negative index counts from the end, and [:4] takes a slice. The last two lines are exactly how the serial reaction time task in Module 4 turns a position from 1 to 4 into a key.

1.3Dictionaries

        
A dictionary stores values under names, called keys, inside curly brackets. You look a value up by its key rather than its position. Every experiment on this site keeps the participant details in a dictionary called info, and PsychoPy reads a stimulus file as a list of dictionaries, one per row. The last two lines are a list comprehension: it takes each row in turn, pulls out its word, and collects the results in a new list.

1.4Loops, decisions and functions

        
A for loop runs the indented lines once for each item in a list. enumerate(..., start=1) also counts the passes, which gives you a trial number for free. if and else choose between two blocks; note the double == when you compare and the single = when you assign. def wraps lines in a function you can call by name, and return hands back its result. Python decides what belongs inside a loop, an if or a function by the indentation alone, so keep it to four spaces.

Your first PsychoPy script Python

        
Every PsychoPy experiment, however elaborate, is built from the same few moves: open a window, draw something to a hidden buffer, flip that buffer onto the screen, wait for an event, and eventually close down cleanly. In this module you write the smallest program that does all of these, then take it apart line by line.


        
1.5The whole program

        
In the Coder, create a file called first_experiment.py and type this in:


from psychopy import visual, core, event

# 1. Open a window
win = visual.Window(
    size=[1280, 720],
    fullscr=False,
    color='black',
    units='height'
)

# 2. Create a piece of text
message = visual.TextStim(
    win,
    text="Welcome.\n\nPress SPACE to continue, or ESC to quit.",
    color='white',
    height=0.05
)

# 3. Show it and wait for a response
message.draw()
win.flip()
keys = event.waitKeys(keyList=['space', 'escape'])

# 4. Close down
if 'escape' in keys:
    print("Participant quit early.")
win.close()
core.quit()

        
Run it with the green Run button. A black window opens, your message appears in white, and the program waits. Press space and the window closes; press escape and you see the quit message in the output pane first.


        
1.6Taking it apart

        
The first line imports three modules. visual holds anything you draw, core holds timing and the clean-exit function, and event reads the keyboard. Module 2 replaces event with a more precise keyboard tool, but it is perfect for a first look.

        
The Window is the canvas. We asked for a windowed 1280 by 720 pixel display while developing, which is far easier than a full-screen window you cannot click out of. For real data collection you would set fullscr=True so nothing else is visible. The units='height' choice matters more than it looks: it means every size and position you give from now on is measured as a fraction of the window’s height, so your stimuli stay correctly proportioned on any screen.

        

          Note
          
In height units, the screen runs from −0.5 to +0.5 vertically, and the centre is (0, 0). A text height of 0.05 is therefore one twentieth of the screen height, which is comfortably readable.

        

        
Nothing appears the moment you create the TextStim. Drawing in PsychoPy is a two-step affair. message.draw() paints the text onto a hidden back buffer, and win.flip() swaps that buffer onto the visible screen in one go, synchronised to the monitor’s refresh. This is why animation in PsychoPy never tears or flickers: you build the whole frame in the dark, then reveal it all at once.

          Watch out
          
If you call draw() but forget win.flip(), you will stare at a blank window and conclude the program is broken. It is not. You simply never turned the lights on. Every visible change needs a flip.

        

        
event.waitKeys(keyList=['space', 'escape']) pauses the program until one of the listed keys is pressed, and hands back a list of the keys it saw. Restricting the list means a stray key press cannot skip your instructions by accident.

        
Finally, win.close() shuts the window and core.quit() ends the program tidily, releasing the screen and any hardware. Always close down explicitly. A script that simply runs off the end can leave a full-screen window stuck in front of everything else.


        
1.7Make it your own

        

          Try this
          
1. Change the background to mid-grey. PsychoPy’s signed colour scale runs from [-1, -1, -1] for black to [1, 1, 1] for white. What value gives mid-grey?

          
Show the answer
            
color=[0, 0, 0]. Zero on each of the red, green and blue channels is the middle of the scale. This is the grey of PsychoPy’s default window, and of the window on this site’s home page.

          

          
2. Add a second TextStim in a different colour, positioned near the top with pos=[0, 0.3], and draw both before the flip.

          
Show one way to do it

title = visual.TextStim(win, text="Hello", color='yellow',
                        pos=[0, 0.3], height=0.06)

message.draw()
title.draw()
win.flip()

            
Create the new stimulus with the other one, near the top, and add its draw() before the existing win.flip(). The order of the two draws does not matter here, because they do not overlap.

          

          
3. Make the program print which key was pressed, not just whether it was escape.

          
Show one way to do it

print("Key pressed:", keys[0])

            
waitKeys() returns a list of key names, so the first key pressed is keys[0]. Put the line straight after the waitKeys() call.

          

        

        
If the second stimulus does not appear, check that you drew it before the flip. Only what has been drawn since the last flip is shown by the next one. This single rule explains the majority of “why can’t I see it” questions you will ever ask.
