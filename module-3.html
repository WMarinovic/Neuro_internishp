Your first R script R

Every analysis script on this site, however different the data, is built from the same few moves: load the tidyverse, get the data into a tidy table, transform or summarise it, and look at the result, usually as a plot. In this module you write the smallest script that does all of these, then take it apart.

3.1The whole program

In RStudio, create a new script (File > New File > R Script) and save it as first_script.R. Type this in:

library(tidyverse)

# 1. A tiny dataset (twelve pretend trials, three blocks of four)
trials <- tibble(
  block = rep(1:3, each = 4),
  rt    = c(0.62, 0.58, 0.60, 0.55,
            0.50, 0.48, 0.52, 0.49,
            0.44, 0.46, 0.43, 0.45)
)

# 2. Transform: one mean per block
by_block <- trials |>
  group_by(block) |>
  summarise(mean_rt = mean(rt))

# 3. Look at the numbers
print(by_block)

# 4. Look at the shape
ggplot(by_block, aes(block, mean_rt)) +
  geom_line() +
  geom_point(size = 2) +
  labs(x = "Block", y = "Mean RT (s)", title = "Getting faster across blocks")

Run the whole script at once with Ctrl+Shift+Enter (Source), or run it line by line with Ctrl+Enter as you did in Module 0. Either way, a small table appears in the Console and a line plot appears in the Plots pane, bottom right.

3.2Taking it apart

        
library(tidyverse) loads the whole bundle in one line rather than one package at a time. tibble(...) builds a data frame, R’s table type: each argument becomes a column, and rep(1:3, each = 4) repeats 1, 2, 3 four times each to give the block column. This is exactly the shape every CSV your PsychoPy scripts write will arrive in later: one row per trial, one column per variable.

        

          Note
          
The |> symbol is the pipe: it takes whatever is on its left and feeds it in as the first argument of whatever is on its right. trials |> group_by(block) reads left to right, like a sentence: take trials, then group by block. Older R code you meet online often uses %>% instead, from a package called magrittr; it does the same job. |> is base R’s own version and the one these modules use throughout.

        

        
group_by(block) followed by summarise(mean_rt = mean(rt)) is the pattern behind almost every analysis on this site: split the rows into groups (here, one group per block), then collapse each group down to a single summary row. The result has one row per block, not one row per trial.

          Watch out
          
summarise() removes one level of grouping as it collapses the data, which occasionally surprises people chaining several group_by() and summarise() calls together. If a later step behaves as though the data were still grouped by something you thought you had summarised away, print the tibble and check: it prints its own grouping, if any, directly under the column names.

        

        
ggplot(by_block, aes(block, mean_rt)) sets up a plot from by_block, mapping block to the x-axis and mean_rt to the y-axis, but draws nothing yet; aes() only maps data to position and appearance. Each geom_...() added afterwards with + draws one layer: geom_line() draws the connecting line, geom_point() adds a marker at each block, and labs() sets the axis titles and a plot title. Every plot in these modules is built by stacking geoms this way onto one aes() mapping.

        

          Note
          
A script only has a working directory once you tell it one, and every analysis script from Module 4 onwards assumes it is the folder containing the data subfolder it needs to read. Session > Set Working Directory > To Source File Location does this for one session; a Project (File > New Project, in the same folder as your script) does it automatically every time you reopen that folder, and is the better habit for anything you will come back to.

        


        
3.3Make it your own

        
Try these in RStudio, or in the browser copy above.

        

          Try this
          
1. Change mean(rt) to median(rt) and re-run. Does the shape of the plot change much, for this amount of data?

          
Show what to expect
            
Hardly at all. The medians are 0.59, 0.495 and 0.445 against means of 0.588, 0.498 and 0.445, because four tidy trials per block contain no outliers to pull the mean away. With real reaction times, which have a long tail of slow responses, the two can differ much more.

          

          
2. Add a fourth block of four made-up reaction times to trials, and update the plot without changing any other line.

          
Show one way to do it

trials <- tibble(
  block = rep(1:4, each = 4),
  rt    = c(0.62, 0.58, 0.60, 0.55,
            0.50, 0.48, 0.52, 0.49,
            0.44, 0.46, 0.43, 0.45,
            0.42, 0.41, 0.43, 0.40)
)

            
Only the data change: 1:3 becomes 1:4, and four more values join rt. Everything after it works on whatever trials holds, so the summary and the plot pick up the fourth block by themselves.

          

          
3. Change geom_line() to geom_col() and see how the same summary looks as bars instead of a line.

          
4. Add filter(rt < 0.55) before group_by(block) and see which rows, and which blocks, disappear.

          
Show what to expect
            
All four trials in block 1 are 0.55 s or slower, so the whole of block 1 disappears, from the summary and from the plot. Blocks 2 and 3 keep every trial. Tick the filter box in the demo above to step through it.

          

        

        
If the Plots pane stays blank after you run the ggplot() lines, check that you ran the whole expression, brackets and all; a plot built across several + continuation lines only appears once R reaches the last line with nothing left to add.

        

          For R users
          
From Module 4 onwards, real experiment data, produced by the very PsychoPy scripts you are about to build, replaces this pretend tibble: it arrives as a folder of CSV files, read in with read_csv() instead of typed by hand with tibble(). Everything else here, the pipe, group_by(), summarise(), and ggplot(), reappears unchanged.
